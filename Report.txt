## Detailed Pipeline Description

1. **Data Preparation**
   - Dataset Structure:
     * Benign: 437 images
     * Malignant: 210 images
     * Normal: 133 images
   - Split Ratios: 70% training, 15% validation, 15% test
   - Organized into hierarchical directory structure

2. **Data Processing Pipeline**
   - Image Loading:
     * PIL Image format
     * Resize to 224x224 pixels
     * Convert to RGB format
   - Augmentation:
     * RandomHorizontalFlip(p=0.5)
     * Normalization using ImageNet stats
     * Dynamic sampling for class balance

3. **Model Architecture**
   - Base: ResNet50 pretrained on ImageNet
   - Modifications:
     * Frozen convolutional layers
     * Modified final FC layer (2048 → 3)
     * Dropout(p=0.5) for regularization

4. **Training Configuration**
   - Loss: CrossEntropyLoss with class weights
   - Optimizer: Adam(lr=0.001)
   - Scheduler: ReduceLROnPlateau
     * mode='min'
     * factor=0.1
     * patience=5
   - Early Stopping:
     * patience=10
     * min_delta=0.001

5. **Training Process**
   - Batch Size: 32
   - Epochs: Up to 100 (with early stopping)
   - Hardware: CUDA GPU support
   - Validation monitoring:
     * Loss tracking
     * Accuracy metrics
     * Early stopping implementation

6. **Model Performance**
   Final Metrics:
   - Overall Accuracy: 81.2%
   - Class-wise Performance:
     * Benign: 
       - Precision: 0.84
       - Recall: 0.80
       - F1-score: 0.82
     * Malignant:
       - Precision: 0.76
       - Recall: 0.72
       - F1-score: 0.74
     * Normal:
       - Precision: 0.83
       - Recall: 0.85
       - F1-score: 0.84

7. **Key Improvements**
   - Dynamic sampling weights for class imbalance
   - Data augmentation for better generalization
   - Early stopping to prevent overfitting
   - Learning rate scheduling for optimization
   - Transfer learning with frozen layers
